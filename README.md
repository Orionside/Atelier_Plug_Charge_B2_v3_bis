# Atelier Plug & Charge B2 v3 — version bis

Copie indépendante de l'atelier [`Atelier_Plug_Charge_B2_v3`](https://github.com/Orionside/Atelier_Formation_Francais/tree/main/Atelier_Plug_Charge_B2_v3), préparée pour expérimenter sans modifier la version diffusée aux apprenants.

L'atelier se lance avec [`index.html`](index.html). Après activation de GitHub Pages depuis la branche `main` et le dossier racine, son adresse sera : https://orionside.github.io/Atelier_Plug_Charge_B2_v3_bis/

Cette copie conserve le code et le contenu d'origine. Seuls l'identifiant des réponses locales et l'adresse de l'atelier dans `contenu.js` ont été adaptés pour que la version bis ne réutilise pas la progression enregistrée pour la version d'origine et ne renvoie pas vers celle-ci.

La synthèse vocale Gemini n'est pas encore intégrée. Son ajout devra préserver l'accès au contenu en cas d'indisponibilité de l'audio et garder les clés API hors du code servi par GitHub Pages.
